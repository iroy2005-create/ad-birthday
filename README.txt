ADARSSHH'S BIRTHDAY WEBSITE — DRAFT

FILES
- index.html: all pages and the full letter
- style.css: scrapbook styling and responsive layout
- script.js: page navigation, envelope/balloon animations, YouTube song controls
- assets/: the page images

YOUTUBE SONGS
The three song buttons embed the YouTube videos you provided. They begin at approximate main-hook timestamps and stop around 35 seconds later, skipping most of the opening tune:
- Dil Na Jaaneya: starts at about 1:04
- Hum Nahi Sudhrenge: starts at about 0:49
- Papa Meri Jaan: starts at about 0:54

These timestamps are approximate, not guaranteed to land exactly on the chorus in every upload. You can adjust the start/end values near the top of script.js after previewing each song. YouTube may prevent embedding for a particular video or show its own ads/sign-in prompts; if that happens, open the video on YouTube instead. Music starts only after a tap because browsers generally block autoplay.

PREVIEW
Keep index.html, style.css, script.js and assets/ together. Open index.html in a browser, or host the folder using GitHub Pages for a shareable phone-friendly link.

PUBLISH WITH GITHUB PAGES
Upload the contents of this folder to a GitHub repository, then open Settings > Pages and enable deployment from the main branch/root. Share the Pages URL once it is published.
